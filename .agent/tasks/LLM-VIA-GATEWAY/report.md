## Відкат

Схема БД не змінювалася; міграцій для відкочування немає. Зберегти попередній
артефакт релізу та налаштування aiupskill у захищеному місці до apply.

Безпечний аварійний відкат LLM-функції: призупинити генерації, відкликати
лише consumer `aiupskill` або прибрати його `LLM_GATEWAY_KEY` із середовища
процесу та перезапустити лише `aiupskill`. LLM-шляхи дадуть явну помилку;
публічні сторінки з уже збереженим контентом залишаються доступними.
Для виправлення адреси/ключа повернути останні працездатні gateway env й
перезапустити той самий процес.

Повертати попередній код можна лише до релізу, що також підтримує шлюз.
Parent цієї міграції `55a6de4` звертається прямо до провайдера: звичайний
revert із відновленням старого provider key порушить обов'язковий маршрут.
Такий legacy rollback потребує окремого рішення власника; автоматичного
або тихого fallback у цьому коді немає. Новий consumer не відкликати,
поки він потрібен активному gateway-сумісному релізу.
